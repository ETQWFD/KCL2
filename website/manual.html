KCL2 使用手册

适用于 KCL2 Windows 版本。Linux 原生版与 JAR 不是现有 WPF/.NET Framework 工程可直接编译的产物，需另行移植。

一、安装

  1. 打开 GitHub Release。
  2. 下载 KCL2 的 Windows 压缩包。
  3. 右键压缩包并选择“全部解压”，不要直接在压缩包窗口中运行。
  4. 建议放到文档、桌面或非系统保护目录。
  5. 运行 KCL2.exe。

二、首次启动

首次启动会显示英文来源和许可声明。继续即表示你知道 KCL2 是第三方修改版，原作 PCL 的作者 龙腾猫跃（LTCat）不负责本版本。

启动器会在程序所在目录创建 kcl 文件夹，用于保存日志、缓存相关配置、自定义图片、音乐和帮助文件。

三、下载 Minecraft

  1. 进入“下载”页。
  2. 选择“游戏下载”。
  3. 选择正式版、快照版或远古版本。
  4. 需要模组时选择 Forge、NeoForge、Fabric 或 OptiFine。
  5. 网络较慢时，可在设置中切换可用下载源。
如果版本列表为空，先检查系统时间、网络和杀毒软件拦截，再查看 kcl/Log1.txt。

四、微软正版登录

KCL2 使用微软设备码流程，不会要求你在启动器内输入 Microsoft 密码。

  1. 进入账户页并选择正版登录。
  2. 首次登录时按窗口提示输入 KCL2 的 Azure Application Client ID。
  3. 浏览器打开微软页面后输入设备码并登录。
  4. 确认 XboxLive.signin 与 offline_access 权限。
  5. 返回启动器等待令牌交换完成。

也可以在启动前设置环境变量 KCL2_MS_CLIENT_ID。Client ID 不是密码，但仍应使用你自己注册的公共客户端应用。

五、版本隔离

建议每个整合包或大型 Mod 包开启版本隔离，避免 mods、screenshots、saves 和配置互相覆盖。已有版本的独立设置可在版本设置中调整。

七、公平启动保护

KCL2 会在游戏进程启动前扫描已知作弊客户端/作弊 Mod 标识、版本 Classpath、自定义 JVM 参数和 Java 注入环境变量。命中未授权 -javaagent、-agentpath、-agentlib 或已知作弊文件时，启动会被停止，拦截记录写入 kcl/FairPlayBlock.txt。

移除相关 Mod/客户端或注入参数后即可重新启动。该检查不下载、不运行真实外挂；对于驱动级、系统级或全新未知混淆方式，不能保证全部拦截。

八、常见问题

Windows 提示缺少 .NET Framework

安装 .NET Framework 4.8 后重新启动。

游戏崩溃

先移除最近新增的 Mod，安装与游戏版本匹配的加载器，再导出日志反馈。

文件没有权限

把整个 KCL2 文件夹移动到非系统保护目录，或检查受控文件夹访问和杀毒软件拦截。

能否生成 JAR 或 Linux 原生程序

现有界面基于 Windows WPF/.NET Framework，不能通过改名直接生成 JAR 或 Linux 可执行文件。Linux 支持需要重建界面或引入跨平台启动器内核。

九、来源与许可

KCL2 基于 Plain Craft Launcher 2，原作者为 龙腾猫跃（LTCat）。关于页保留英文署名和赞助原作者入口，仓库保留 PCL 分发许可证。KCL2 的修改部分按适用许可发布，软件按现状提供，不提供额外担保。
