当常见启动器暂时不可用时，
仍要有一个能进入游戏的入口。

KCL2 基于 Plain Craft Launcher 2 二次开发，保留版本下载、加载器安装、整合包管理、版本隔离与微软正版登录。版本文件默认同时走 Mojang 官方源与 BMCLAPI 镜像源，任一源失败会自动切换，支持多线程与断点续传。

下载 KCL2（单文件 EXE） .NET 依赖补丁（仅启动报错时需要）
解压后只有一个 KCL2.exe，首次运行在同目录生成 KCL 与 .minecraft 两个文件夹。要求 Windows 7 及以上 64 位、已安装 .NET Framework 4.8。

启动页

离线与正版登录、游戏用户名、版本入口，沿用 PCL2 的界面布局，默认绿色主题。

下载页

直接拉取 Mojang 官方版本清单，正式版、预览版、远古版分组展示，可下载并安装原版与各类加载器。

关于与更新

保留原作者与上游的英文署名；每次启动自动检查本仓库更新，可选择立即更新、以后再说或忽略该版本。

KCL CE（社区版）实拍

启动页

社区版与 KCL2 同一套代码与界面，绿色主题、正版 / 离线入口一致，单文件启动。

下载页

真实拉取版本清单并下载，社区版走独立的更新通道与公告，不与主力版互相干扰。

关于与鸣谢

同样保留龙腾猫跃 / LTCat 与 PCL 上游的英文署名，改动由 ETC Team 维护。

真实可用的版本下载官方 + BMCLAPI 双源、多线程、断点续传与失败重试，解决下载慢和更新中断。
微软正版登录支持正版账号授权登录；登录授权名称显示为 KCL2。
单文件分发全部程序集内嵌进一个 EXE，不释放多余 DLL，配置统一写入 KCL 文件夹。
启动前公平性检查识别常见作弊客户端 / 作弊 Mod 与 JVM 注入参数，命中则不启动并写入日志。
整合包兼容保留版本隔离与整合包元数据读写，整合包安装目录与原版习惯一致。
软件内自动更新比对本仓库最新提交，更新包在软件内下载并自动替换重启。
