选择版本下载

三个版本共用同一官网与后台。Windows 主力用 KCL2；偏好社区渠道用 KCL CE；安卓手机用 KCL。全部支持微软正版登录与 BMCLAPI 加速下载。

KCL2Windows · 主力最新构建 2026-10-25

基于 Plain Craft Launcher 2 的单文件启动器。解压即用，首次运行在同目录生成 KCL 与 .minecraft 两个文件夹。

系统：Windows 7 及以上 64 位，需 .NET Framework 4.8。单文件 EXE，无多余 DLL。

下载 KCL2（ZIP） 单独下载 KCL2.exe 启动报错？下 .NET 补丁

KCL CEWindows · 社区版v2.15.8

基于 PCL Community 官方社区版（现代 C# / .NET）改造，界面与 KCL2 一致，走独立更新通道与公告。

系统：Windows 10 / 11 64 位（.NET 运行时已内置，免安装）。不确定电脑架构就下 x64。

下载 KCL CE（版本页，含 x64 / ARM64） KCL CE x64 ZIP（直链）

KCLAndroid · 手机版最新构建 2026-10-24

基于 FCL（Fold Craft Launcher）再发行，在手机上运行 Minecraft Java 版，支持模组加载与全版本。

系统：Android 8.0 及以上（arm64 / armv8，主流手机均可）。正式版，安装前请卸载旧版本以免残留地区提示。

下载 KCL 手机版 APK

.NET Framework 4.8 依赖补丁仅 KCL2 需要

仅当双击 KCL2.exe 提示缺少 .NET Framework 时才需要。运行后自动下载安装依赖，完成后会提示并退出。KCL CE 与手机版无需此补丁。
